# OPC / 超级个体落地清单（Web3 防骗工具箱）

> 本技能由《价值互联网产业应用蓝皮书（2025）》经 cangjie-distill 蒸馏流水线提取编排，帮助普通用户识别真假 Web3、厘清合规边界、避开资金盘陷阱。

## 功能简介
面向中文 Web3 内容创作者、个体创业者、自由职业者。当用户想搞清楚"个人如何在 Web3
  共建里接单、定位、靠通证积累回报"时激活。例如：不知道自己能接什么任务、想做轻资产
  一人公司/超级个体、想知道数字游民如何远程参与产业链分工、如何把零散能力变成可计价的
  模块任务。不适用于：企业在设计社区经济模型（用 S6 共建社区运营框架）、在设计通证分配
  规则（用 S5 贡献计量与分配设计器）、在做境内合规判断（用 S2 合规边界红线检查）。本
  skill 聚焦个体侧的"我能接什么、去哪接、怎么累计"落地清单，而非平台侧组织设计。

## 安装方式

### 方式一：从 ClawHub 一键安装（推荐）
在 ClawHub 搜索 `opc-individual-checklist`，或用 CLI：
```bash
clawhub skill install opc-individual-checklist
```

### 方式二：从 GitHub 安装
```bash
git clone https://github.com/63619990/opc-individual-checklist.git
cp -r opc-individual-checklist/ ~/.workbuddy/skills/
```
重启 WorkBuddy 后，对话出现相关信号即自动激活。

### 方式三：手动安装
将本仓库 `opc-individual-checklist/` 目录整体复制到 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）。
